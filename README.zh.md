# The Flea

《Probably Stolen》的模組。

我很喜歡「被動式多人連線（passive multiplayer）」的設計，以前還幫《The Long Dark》做過一個類似的模組。放到《Probably Stolen》裡，最直覺的做法就是讓玩家互相交易。不是什麼新點子，有人做過了我知道，但我還是想做一個比較平衡、自然融入原本玩法，沉浸感比較好的交易模組。

「跳蚤」（The Flea）是個可以用電話叫來的商人。他會收你店裡不要的東西，也會帶其他玩家賣掉的貨過來。東西的行情會隨著大家實際買賣的狀況漲跌。

## 啟用方式

1. 進到 Mods 選單，選 **The Flea** 按 **Activate**。
2. 跳出網路和 Steam 權限提示時按同意，然後重開遊戲。
3. 電話簿裡就會多出他的號碼：**3532**。

## 玩法

1. **打電話到 3532**，跟他說你想找哪類東西。他會跟你約時間，通常是隔天，偶爾要等 2 到 3 天。
2. **約好的那天照常開店。** 他會排在一般客人後面進來。
3. **跟他買東西。** 他會把貨擺在櫃檯上，大部分是別的玩家賣掉的，剩下幾件是他自己帶的。
4. **把東西給他賣。** 跟賣東西給一般客人一樣直接拿給他就好。他是幫你拿去寄賣，所以當下不會給錢。
5. **下次叫他來拿錢。** 等你下次再打電話叫他來，他就會把上一批賣掉的錢結給你。

如果還沒輪到他進門你就先關店了，他會改在你下次開店那天過來。

## 價格怎麼算

- **每樣東西都有市場行情，** 範圍在原價的 50% 到 150% 之間。
- **賣的人多就跌，買的人多就漲。** 如果大家都一直塞同一種東西給他，那樣東西就會變便宜。
- **沒人動的話，價格會在幾個小時內慢慢回到原價。**
- **買賣他都會抽一成（10%）：** 跟他買要多付 10%，請他賣會被扣 10%。
- **結帳金額看的是「他付錢那天」的行情，** 不是你把東西給他那天的價格。平板上顯示的只是預估價。

遊戲裡的事件跟店面加價（Markup）對他都沒用，不過香水之類的效果（Perks）還是會算。

## 商人等級

跟他交易越多次，他每趟帶來的貨跟能收的東西就會越多。不管你是跟他買還是請他賣，只要有錢過手就會算進累積金額裡。

| 等級 | 累積交易金額 | 每趟帶來的貨／能收的件數 |
|---|---|---|
| 1 | 0 | 4 |
| 2 | 2,500 | 6 |
| 3 | 7,500 | 8 |
| 4 | 20,000 | 10 |
| 5 | 50,000 | 12 |

## 他不收的東西

- 違禁品，或是風頭還沒過的贓物。
- 機器、門禁卡，還有標示為不可轉售（Not for resale）的東西。
- 價值是 0 的東西。

拿這些給他只會被退回來，不會有什麼損失。

## 假貨

你拿給他的東西他都會檢查，假貨有九成機率會被他抓包。被抓到的話就只能用原本的爛價錢賣；但要是沒被他看出來，他就會當成真貨付你錢。

反過來也是一樣：別的玩家塞給他、又沒被他看出來的假貨，帶到你店裡時看起來也跟真的一樣。跟他買東西記得自己先檢查過。

## 跟他買來的東西

- **`賣家：`**（`Seller:`）會顯示原本賣家的 Steam 名稱，對方開匿名的話就會顯示 `匿名`（`Anonymous`）。
- **`賣家：未知`**（`Seller: Unknown`）代表這件是他自己生出來的貨。另外如果抽到別的模組的物品、但你沒裝那個模組，也會換成這種。
- **大部分東西都會維持原本的狀態，** 像是槍上面裝的配件、或是瓶子裡裝了什麼。不過負面缺陷（Defects）不會跟著過來。
- **沒買的貨他收走就沒了，** 下次不會再帶同一批來。

## 設定

在 Mods 選單裡點這個模組旁邊的齒輪就能改：

| 設定 | 說明 |
|---|---|
| **市場代碼**（Market code） | 代碼一樣的玩家只會跟彼此交易。`0` 是預設市場。 |
| **匿名出售**（Sell anonymously） | 賣出去的東西不要顯示你的 Steam 名稱。 |
| **隱藏其他賣家的名稱**（Hide other sellers' names） | 把你畫面上所有賣家的名字都改成 `跳蚤市場`。 |
| **兩次致電的間隔天數**（Days between calls） | 打完電話後要隔幾天才能再打給他，預設是 1 天。 |
| **市場網址**（Market server URL） | 除非你自己架伺服器，不然不用動。 |

如果只想跟朋友自己玩，大家把**市場代碼**設成同一個數字就好。不過這組代碼不算密碼，別人要是剛好猜到同一個數字一樣進得來。

## 連不上伺服器的時候

如果他要來的那天連不上伺服器，他會自動晚一天再來，東西跟錢都不會不見。要是隔天還是連不上，他還是會照常進店，只是帶來的會全部是他自己的貨，欠你的錢則會用他最後記得的行情算給你。

## 模組會傳送哪些資料

只有在他約好要來的那天、你開店營業的時候，模組才會連去市場伺服器。打電話的當下不會傳任何東西。

連線時會傳這些資料：

- 你交給他寄賣的物品內容。
- 你的 Steam 名稱，用來顯示給買到的人看。開**匿名出售**就會關掉。
- 這份遊戲安裝時隨機產生的 ID，跟你的 Steam ID 無關。
- 你的市場代碼，還有你在電話裡說想找哪類東西。
- 你前幾次跟他買了哪些二手貨。

就跟連一般網站一樣，伺服器看得到你的 IP，但只會存下打亂後的結果，用來防止有人狂洗商品列表。

賣家名稱沒有經過審核。如果不想看到別人的名字，可以把**隱藏其他賣家的名稱**打開。

## 其他要注意的事

- **還沒拿到的貨款是記在存檔裡的。** 如果你讀檔回到把東西給他之前，東西就會回到店裡，那筆交易也會當作沒發生過。
- **寄賣的東西一定拿得到錢，** 就算市場上同類型的貨太多、你的東西沒被抽出去給其他玩家買，時間到了他還是會付錢給你。
- **分不出東西是不是作弊刷出來的。** 會在意的話，建議改用私人的市場代碼。
- **如果中途拆掉模組，** 電話簿裡還是會留著他的號碼，但還沒結清的錢就拿不回來了。
